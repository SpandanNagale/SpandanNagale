| Project | What it does | Stack |
|---------|-------------|-------|
| **[DataSleuth](https://github.com/SpandanNagale/DataSleuth)**  | **Multi-agent autonomous data analyst** — Profiler → Hypothesis Generator → Coder → **Critic** → Visualizer → Report Synthesizer pipeline, where a Critic agent **rejects hallucinated or statistically invalid conclusions** before they reach the report. Interactive trace viewer UI. Fully local. | LangGraph · Ollama · FastAPI · SSE |

Nano (22.9M) and Small (42.1M) variants trained end-to-end. | PyTorch · SentencePiece · nanoGPT-style |
| **[Self-Healing Hybrid RAG](https://github.com/SpandanNagale/Self-Healing-RAG)** | Production RAG with **dense + BM25 hybrid retrieval (RRF)**, cross-encoder reranking, faithfulness verification, and a background **index-healing job** that repairs stale embeddings automatically. | LangGraph · FastAPI · SSE · RAGAS |
| **[DocIntel](https://github.com/SpandanNagale/DocInte)** | Document intelligence for **Indian financial documents** (GST invoices, bank statements, salary slips) — Donut fine-tuning + OCR-heuristics hybrid routing, LightGBM classification, **~683ms p50 serving**. | Donut · LightGBM · FastAPI |
| **[ARIA](https://github.com/SpandanNagale/ARIA)** | Fully local, JARVIS-style **voice assistant** — wake-word detection, GPU-accelerated STT (faster-whisper), local LLM reasoning, persistent memory, screen vision, and tool-calling. Built end-to-end on an RTX 5070. | Ollama · Whisper · Piper · ChromaDB |
| **[ML-Agent](https://github.com/SpandanNagale/ML-Agent)** | AI agent that **automatically builds, trains, and self-heals end-to-end ML pipelines** from a single problem statement — 9-agent system using local LLMs. | CrewAI · Ollama · scikit-learn |
| **[CrewAI Research Pipeline](https://github.com/SpandanNagale/Crewai-Research-pipeline)** | Production-ready multi-agent research API — Planner → Researcher → Writer → Critic, SSE streaming, **automated LLM-as-a-judge eval scorer**. | CrewAI · FastAPI · Gemma |
| **[Research Copilot](https://github.com/SpandanNagale/Research-Copilot)** | High-performance AI research tool — fetches papers from ArXiv, **summarizes & clusters them by topic**, and enables chat with the corpus. | LangChain · FastAPI · ChromaDB |
